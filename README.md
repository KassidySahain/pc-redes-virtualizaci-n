# 💻 Propuesta de PC para redes y virtualización

Propuesta académica de configuración de un computador orientado a mi formación como estudiante de la Licenciatura en Redes Informáticas en la Universidad Tecnológica de Panamá.

## 🎯 Objetivo

Proponer una configuración de hardware para actividades de estudio, simulación de redes y uso de máquinas virtuales, considerando la función de los componentes y su compatibilidad.

## 🧩 Componentes propuestos

| Componente | Modelo o capacidad |
|---|---|
| Procesador | AMD Ryzen 7 9700X |
| Placa madre | MSI MAG B650 TOMAHAWK WIFI |
| Memoria RAM | 32 GB DDR5 (2 × 16 GB) |
| Almacenamiento | WD_BLACK SN850X de 2 TB |
| Refrigeración | Thermalright Peerless Assassin 120 SE |
| Fuente de alimentación | Corsair RM750e de 750 W |
| Gabinete | Fractal Design Pop Air |
| Gráficos | Gráficos integrados del procesador |

## 🌐 Relación con mi carrera

El estudio de redes también requiere comprender los equipos que permiten ejecutar herramientas y entornos de práctica. Esta propuesta explora una configuración destinada a:

- Utilizar simuladores de redes.
- Crear entornos de aprendizaje con máquinas virtuales.
- Realizar tareas académicas y documentación técnica.
- Ampliar mis conocimientos sobre hardware y compatibilidad.

## 📌 Alcance del proyecto

Este trabajo es una propuesta documental. El equipo no fue ensamblado ni sometido a pruebas de rendimiento.

Antes de una compra o un montaje, se debe verificar la versión de BIOS necesaria, el modelo específico de memoria RAM y las dimensiones y conexiones de los componentes. La cantidad de máquinas virtuales que podrían ejecutarse dependerá de los recursos asignados y de las tareas realizadas.
